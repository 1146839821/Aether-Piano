# P01｜离线高精度琴槌-弦参考模型 — Codex 可执行任务

> **开始条件：** P00 最小工程具备可重现的构建/测试。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

先用数值正确的离线 Python/高精度参考模型，描述 C4 的琴槌撞击与一维弦振动，建立后续实时波导实现的真值近似。

## 必须实现的事项

1. 阅读 Bank 2000/2003 与 Smith 相关章节，写 `experiments/P01/model_assumptions.md`：状态变量/单位/边界/能量定义，尤其是接触力 `F=K[max(0,x_h-y_s)]^p` 的单位与符号。
2. 以 C4 (MIDI 60, A4=440 目标 261.625565Hz) 为起点。单一理想弦模型先进行自洽检查，再引入简化刚性弦；没有实测数据，参数须在 `reference_parameters.json` 标注 `synthetic_research`。
3. 使用 Python/SciPy 实现可调步长 ODE/PDE 近似或有理论约束的高精度离线求解器；描述积分方法、空间分辨率、边界条件与数值色散。避免把普通衰减正弦波称为物理参考。
4. 实现非线性琴槌击弦：初始琴槌速度、接触/离开判据、力、动量与能量估计；接触期间对钢琴弦外力具有时空定位。
5. 输出三档琴槌初始速度（与 MIDI velocity 的映射先单独、显式规定），禁止逐条响度归一化；将 WAV/接触力曲线/谱图输出到 P01 文件夹。
6. 编写能量与离散精度验证脚本：比较更小时间步下峰值力、接触时间、频率和波形收敛，而不是声称“理论上稳定”。
7. 为未来 C++ 写一份 `hammer_string_reference_interface.md`，规定参考输入和输出的数值数组与单位。

## 实际测试与复现

- 同一场景使用至少三档时间步/空间精度，输出差异表和图。要求误差随精度提升总体收敛；若不收敛，BLOCKED。
- 无输入能量测试、施加外力时的能量流检查，检测所有状态是否有限；极端合法参数不能静默爆炸。
- 记录 C4 的 `f0` 与非谐性目标（若存在），清楚区分理论预期、求解器数值误差和真实钢琴参考差距。
- 真实执行 Python test 和相应 CTest wrapper，报告环境与命令。
