# P08｜高级非线性、纵向波、双极化和模型对照 — Codex 可执行任务

> **开始条件：** P07 已完成可测/可复现的基线；本阶段属高风险可选研究，不应阻挡 P09/P10 的工程开发。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

通过受控 A/B 证据判断更复杂的物理模型是否值得合入主引擎，而不是因为“模型更复杂”就宣称更逼真。

## 必须实现的事项

1. 从 R07/R08 选定一至两个实验：例如横向双极化与阻抗差异、纵向波/几何非线性、琴毡接触滞回、复杂重复击弦、全模态琴弦对照。
2. 每个实验写出理论方程、能量/单位、预期可听改善、CPU 上界、参考论文和潜在别名/数值误差。
3. 不直接替换主引擎。添加 feature flag 和清晰隔离的研究模块/branch，保留 baseline 模式及一致参数。
4. 对相同 MIDI、速度、音高、踏板，导出相同响度基准的 A/B WAV，分析残差、非谐性、纵向瞬态、aliasing、接触波形。
5. 对复杂模型建立 CPU/内存/响应的开销表，必要时探索 SIMD/多速率并与普通多速率折衷比较。
6. 结合真实钢琴资料与盲听评估，做 ADR：`adopt / reject / defer`，显式给出推翻原假设的实验信息。

## 实际测试与复现

- 开关模型回归无 NaN/Inf 和非物理自激；任何新非线性必须有极端合法参数测试。
- 将新模型与 P07 基线在至少三个音区、多档力度测试；记录混叠产物与性能损失。
- 如果无法找到可测改善或超出实时预算，不进入主分支；结果以研究成果结题也可以通过本阶段“评估完成”。

## 交付文件

研究模块/feature flags、模型对照、声学和性能分析、完整 ADR、`experiments/P08/PHASE_REPORT.md`。

## 质量门 / 不允许的捷径

通过是“研究决策有证据”，不是“必须采纳复杂算法”。任何未证实的音质改善不得作为产品宣传。
