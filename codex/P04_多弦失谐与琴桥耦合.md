# P04｜同音多弦、琴桥机械阻抗与拍频 — Codex 可执行任务

> **开始条件：** P03 全音域和复音测试通过。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

模拟每键 1–3 弦、真实失谐与**无源琴桥耦合**，从状态交互自然产生拍频及两阶段衰减，而非后置 Chorus。

## 必须实现的事项

1. 将每键的 string bank 支持不同弦数/失谐/频散/损耗，弦数由参数/文献和测量来源决定，音区边界可配置。
2. 设计共享琴桥的力/速度机械端口与无源散射网络；在文档写出端口功率 `P=F*v` 的符号约定、导纳、损耗和离散稳定域。
3. 保证同音弦能量交换、反射与远端边界逻辑正确；设计可切换 `independent_strings` / `coupled_strings` 测试模式。
4. 对与真实钢琴近似的微失谐参数输出拍频包络和两阶段衰减，并对比只有频率偏移无耦合的基线。
5. 建立不同弦数/琴桥阻抗/边界参数的网格测试，包含无输入能量测试、强奏/踏板接口压力测试。
6. 用批量离线分析报告拍频率、早/晚衰减斜率、分音位置、CPU 每键成本；记录物理近似。

## 实际测试与复现

- 耦合与独立模式均输出 A/B WAV 和度量表；用同样总能量及输出增益进行比较。
- 无外力、无主动元件且无损耗的网络，应不产生无界能量；有损耗条件下应衰减。记录误差容忍度与长度。
- 测试所有 1/2/3 弦组合、极端失谐、多音和弦、快速重触发、多个桥分组。
- CTest、CLI 和 RT allocation 检查全部实际运行并保留日志。

## 交付文件

弦组/桥口模块、被动网络设计说明、拍频与两阶段衰减的 WAV/图/统计、`experiments/P04/PHASE_REPORT.md`。

## 质量门 / 不允许的捷径

通过：听觉变化对应可测的物理状态耦合、能量分析正确、不同弦数组合稳定；不得用泛化 chorus 作为耦合算法的唯一实现。
