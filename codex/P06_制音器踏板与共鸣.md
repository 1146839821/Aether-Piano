# P06｜制音器、三踏板与未击弦共鸣 — Codex 可执行任务

> **开始条件：** P05 琴桥/音板模型具备可靠状态与稳定性边界。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

让琴键、踏板、琴弦共鸣和制音器拥有真实的交互状态机，处理原声钢琴演奏中最容易暴露虚假感的场景。

## 必须实现的事项

1. 在 `src/performance` 创建按键/琴槌/制音器状态机：Note On、Note Off、重复键、同音重叠、快速踏板变换；所有事件严格按 sample offset。
2. 实现 CC64 sustain：模拟踏板位置和制音器离弦/接触的动态，而不是尾部增益包络。支持连续半踏板；开关型控制器也可用。
3. CC66 sostenuto：踏下瞬间只锁存符合条件的已抬起制音器的音符；后续触键不自动加入集合。CC67 una corda：实现可校准的接触机制近似，按型号/数据定义并标记近似。
4. 将 Damper 模型与弦接触位置/阻尼注入耦合，不让键释放直接清空弦 buffer；重新踩踏延音应保留未完全衰减的弦状态。
5. 让没有被敲击的琴弦通过琴桥受激发，添加主动/共鸣弦状态和 CPU 节制策略；可设置纯物理和节约 CPU 两种模式并测误差。
6. 支持 silent key / chord resonance / half-pedal / repeated note 自动化 MIDI 用例，生成相应 WAV 和时序日志。
7. 添加踏板变化引起的能量源判定与衰减检查，防止某些开/关序列激发不真实自激。

## 实际测试与复现

- MIDI 测试：CC64=0/32/64/96/127，CC66 capture/release，CC67 toggling，pedal before/after Note On，跨块多事件同 sample offset。
- 对每个测试导出弦状态/制音器位置/相应音频，特别记录键释放后仍有共鸣、松踏板之后自然耗散是否合理。
- 和弦+重踏板下 CPU/RT alloc/no NaN 监控；与无共鸣版 A/B 可重现。
- 开关并非只有“更长混响”；必须测共鸣音的实际频率参与和总能量。

## 交付文件

踏板状态机、Damper 模型、Sympathetic Resonance 模块、MIDI 回归用例、A/B 音频、报告。

## 质量门 / 不允许的捷径

通过：踏板状态机语义正确、弦状态连续、共鸣声学上可测且不引入非物理自激，CPU 上界清楚。
