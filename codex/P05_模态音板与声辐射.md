# P05｜模态音板、琴桥负载反馈和立体声辐射 — Codex 可执行任务

> **开始条件：** P04 无源同音弦/琴桥耦合运行可靠。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

建立可辨认的“音板声学特征”，明确分离机械负载与空气辐射；让音板成为与琴弦相互作用的乐器组成，而非尾部混响。

## 必须实现的事项

1. `SoundboardModes` 以稳定二阶离散系统或同等表示实现可调模态组：频率、阻尼、桥口驱动权重、L/R 辐射权重，并在 `prepare` 计算滤波器系数。
2. 初版使用单向 `bridge force -> modes -> radiation` 作为稳定基线；第二步加入音板动导纳对桥口的**反馈**，需避免代数环和无源性违反。提交明确的接口动力学、状态和计算顺序。
3. 证明零外力条件下音板模态不自激，检查接近 Nyquist 模式是否稳定；参数跳变使用非 RT 预计算/平滑或受控交叉渐变。
4. 支持切换无音板、单向辐射、反馈耦合三种模式，比较弦衰减、谱和音板响应变化。不要用效果器混响当音板替身。
5. 建立左右声辐射权重与输出电平基准；空间感来自不同模态辐射，不是简单增宽。可加入**可关闭**的房间混响作为纯后处理，但独立参数与测试。
6. 先使用研究型模态参数显式标注未测量；为 P07 的桥口/音板实测数据拟合保留接口。
7. 生成单音、琶音、和弦 A/B WAV、模态/能量/CPU 统计。

## 实际测试与复现

- 二阶模态频率、衰减时间和稳定性单位测试；多个模态 `0, 1, 16, 64, N` 的边界。
- 桥口零输入功率和跨模块反馈能量检查；至少两种采样率的极点稳定性。
- 对照上阶段的弦本体音准与频散，不允许音板算法无故改变音高。
- 完整运行 CTest / CLI / 轻重负载 callback profiling；允许研究数据尚缺，但必须如实标注。
