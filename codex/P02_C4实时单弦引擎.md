# P02｜C4 实时双向波导与物理撞击 — Codex 可执行任务

> **开始条件：** P01 参考模型通过能量/数值收敛验证；P00 DSP/CLI 工程可编译。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

以 C4 单根琴弦为目标，实现能在实时音频回调中运行的双向数字波导、物理接触、色散和频率相关损耗。

## 必须实现的事项

1. 在 `src/dsp/string` 实现双向行波延迟/击弦点波形读取与反作用，包含合理的端点反射和琴桥端初始近似；写注释解释波变量、阻抗与边界。
2. 实现分数延迟插值以及调音方程；不能只设置 `length=fs/f0` 忽略往返与滤波群延迟。
3. 设计稳定 all-pass 色散模块与被动 loss 滤波器；提供 `B=0` 与 `B>0` 的可对比模式，测出每阶泛音偏移。
4. 连接离线参考琴槌-弦交互，采用稳定实时离散化/隐式求解器。允许显式切换过采样，但必须配能量/混叠测试。
5. `PianoEngine` 先实现 C4 一个 voice：Note On 用键速/初始槌速打击，Note Off 先基础制音（P06 精修）；支持重触发时旧弦状态保留。
6. 在 CLI 输出 MIDI velocity 24/80/120 各自自然响度的 C4 WAV 和物理量日志，与 P01 参考对比。
7. 把物理参数与音频状态分离；prepare 预分配缓冲和查表，`process` 不能创建/删除对象。
8. 建立特征回归：f0、部分音偏移、谱质心、早/晚衰减、hammer 接触波形、运行耗时。

## 实际测试与复现

- 运行 Debug/Release CTest、离线 WAV 与分析脚本。至少测试 44.1k/48k/96k 的基本稳定/调音；本阶段明确 48k 为主验收。
- 与 P01 小时步参考比较第一轮击弦瞬态和谱峰；不要求已达到实物钢琴音质，但须记录差异与原因。
- 分数延时滤波极点稳定、全通幅值、损耗频响及随力度变化的谱特征须有数字证据。
- 统计 RT allocations 为 0（在可检测环境）、无 NaN/Inf；极弱/极强、最快重复、静音/重置都要测试。

## 质量门 / 不允许的捷径
