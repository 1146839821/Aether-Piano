# P03｜88 键、调律和稳定复音 — Codex 可执行任务

> **开始条件：** P02 单音通过声学和实时测试。。这是完整的执行任务，不是仅供讨论的需求草案。

## 本阶段唯一目标

把已验证的单音物理核扩展到 A0–C8 的可演奏音域，分配合理资源并处理 MIDI 的重叠事件、复奏与调律。

## 必须实现的事项

1. 定义 MIDI 21–108 的 `NoteParameters` schema、频率/非谐性/损耗/琴槌的音区曲线、标定状态与 `source_ref`。未知参数使用显式 `ESTIMATED` 标识。
2. 使全部音符合适的 delay length、filter tap/loop precision，并在 `prepare` 阶段预计算；重点处理 27.5 Hz 的超长延迟与高音短延迟的数值边界。
3. 建立可以处理多 Note On、Note Off、同音重复、Voice 释放和零/非标准块大小的 `PerformanceEngine`，保留弦状态，不把每次重触发当新的独立“样本文件”。
4. 延音踏板在 P03 可用简化制音状态，但接口应为 P06 的完整制音模型预留位置。
5. 加入参考 A4=440、可配置拉伸调律曲线与不同采样率下的校准；任何改变 B 的功能不能悄悄改变基频。
6. 离线生成音阶、跨八度琶音、四声部和弦与同音极快重复 MIDI；保存事件时间表与 WAV。
7. 建立 voice/CPU 统计、活跃弦数量监视、静音判定滞后与可重复复音 benchmark。

## 实际测试与复现

- 全 88 音的基本 `f0`、finite 状态、无宿主块边界爆音测试；区分 target equal/stretch tuning。
- 1/8/32/64 note scenarios 下的 callback 时长与占用；仅记录真实机器测得结果，不虚报可达复音。
- 对每条音生成至少一次 velocity 80 的短 WAV 或频率/能量摘要；人声化和听觉检查应有报告。
- 事件 sample-offset 测试：跨块 Note On/Off、同样样本的多个事件、重叠/复用 note 与延音简化状态。

## 交付文件

全音域参数/复音组件、音区映射、事件回归、音频与 CPU 数据、`experiments/P03/PHASE_REPORT.md`。

## 质量门 / 不允许的捷径

通过：全音域无断裂和数值失稳，在选择的硬件上稳定复音；无数据来源的参数始终标为估计，不得提前宣传真实特定钢琴型号。
