# 00｜项目章程：目标、范围与成功标准

## 北极星目标

开发可长期维护的原创三角钢琴物理建模引擎：以击键速度驱动的**非线性琴槌-琴弦相互作用**为起点，实时模拟振动、失谐、衰减、琴桥负载、音板共鸣和踏板响应；在真实演奏与盲听测试中持续缩小相对于高端商业物理建模钢琴与实物钢琴的差距。

不是：对现有钢琴插件进行代码还原、复制专利/私有预设、采样回放冒充物理模型、以视觉界面替代声学研发。

## 产品目标分层

| 层级 | 定义 | 不包含的承诺 |
|---|---|---|
| G0 可运行 | 可构建插件、接收 MIDI、输出音频、离线渲染、保存状态 | 不意味着真实音质 |
| G1 模型可验证 | 单音物理机制在数值、频率、衰减和力度方面可与参考数据对比 | 不意味着全音域一致 |
| G2 音乐可演奏 | 88 键、复音、踩踏板、重复击键可靠 | 不意味着达到 Pianoteq 级别 |
| G3 高保真 | 真实钢琴数据标定、持续迭代盲听、声学指标达标 | 不能只用主观评价宣布成功 |
| G4 可发布 | VST3/AU、安装包、授权、宿主兼容、稳定性能 | 不意味着已经完成商业许可审查 |

## 体验目标

- 88 键标准演奏音域；真实钢琴各区段单/双/三弦配置按实物测绘或合法来源建立，而非一刀切。
- 弱奏—强奏音色呈连续变化；同音快速重复不产生不合理的状态重置。
- 键释放、半踏板、Sustain、Sostenuto、Una Corda 与共鸣都由真实机制近似，不仅是增益自动化。
- 立体声输出能体现琴桥/音板/辐射特性；混响可关闭以独立检验干声。
- 明确的物理参数可编辑与可重现预设；采样率变化不改变目标音高/声学行为。

## 量化的候选指标（需实验确认可行性）

| 指标 | 研发门槛 / 工程目标 | 测量前提 |
|---|---|---|
| 音高 | 已校准音符的主要基频误差 ≤ 5 cents（首版），后期追求更低 | 定义目标调律、排除不适用的瞬态窗口 |
| 频散 | 测得泛音频率 vs 模型输出逐阶对齐并报告误差 | 同音高、同力度、同一参考钢琴 |
| 动态 | 多力度 RMS/谱质心/接触时间变化有规律，不能以单一音量缩放代替 | 不对每条音频单独归一化 |
| 稳定性 | 测试矩阵中 0 NaN、0 Inf、无无界能量增长 | 明确测试时间、参数边界 |
| 低延迟 | 不在 audio callback 进行分配/锁等待/文件 I/O | 构建与运行时实时分配探针 |
| 性能 | 每块最坏耗时 < 所设预算；初始设计预算可设 70% 块时长，留下余量 | 在**指定硬件和固定复音场景**记录 p99 / max |
| 盲听 | 专家按标准测试表比较触键、重复音、和弦、踏板、音色空间感 | 记录样本量、随机化、音量匹配 |

上表不是既有成果。严禁将候选门槛写成“已达到”。

## MVP 非目标

首三个阶段不做：多钢琴品牌完整复刻、无限复音、实时切换大型物理模型、3D 渲染界面、插件云账户、AI 自动混音、音源市场发行。

## 约束和边界

- 开源论文可以研究，但论文原文及图表不能无授权整篇复制到产品文档；第三方代码必须检查许可证。
- 参数表属于结构与示例；没有测量数据的音符允许被标注为 `estimated`，不能称为 `measured`。
- “逼近 Pianoteq 的体验”是对外可比较的**研发目标**，不是能保证达到的技术里程碑，也不意味着访问其源代码或专有算法。
- 商业发布日期只有在声学测试、宿主验证、许可证审查与 QA 后才能决定。

## 重要决策

- **首选：** 双向波导 + 非线性琴槌 + 模态音板 + 共享耦合；**备选：** 完整模态琴弦引擎。采用数据驱动的 A/B 性能和音质门选择，不把某种算法当成信仰。
- **先声学后 GUI：** 单音正确性先于功能数量。
- **基准分离：** 高精度离线求解器、实时 DSP、插件包装三套实现/接口边界清晰。

## 完成的判断者

Codex 可以提交代码和测试证据；声学负责人决定声学模型是否有效；具备钢琴演奏经验的评估者决定可演奏性；工程负责人按真实宿主及机器性能决定发行资格。没有这些角色时不得自动声称 G3/G4 已完成。
