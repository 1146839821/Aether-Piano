# ADR-0004: P03 88 键参数库与固定容量复音

- 状态：Accepted（P03 范围；性能阶段门见 P03 报告）
- 日期：2026-11-03
- 背景：P02 只有 C4 单弦。P03 需要扩展全音域、样本偏移 MIDI 事件、持久同音重触发、简化踏板和可重复性能测量，同时保持 JUCE 独立 DSP 核心。
- 证据：`experiments/P03/note-pitch-summary.csv`、`inharmonicity-tuning.csv`、场景 WAV/事件表、双配置 CTest、polyphony benchmark 与宿主记录。

## 决策

以 MIDI 21–108 的固定数组保存一份 `WaveguideString` 状态/每键。数组及滤波器延迟缓冲在 `prepare` 建立；回调不分配内存。`prepare` 还会让所有弦经过 128 个样本的短预热，再复位状态，以触及实时路径。相同音高的 Note On 再次触发同一个琴槌状态而保留传播波；重叠 Note On/Off 以每键计数配对。CC64 仅延长踏板按下期间释放的音；已开始衰减的音不会被之后的踏板按下重新延长。CC64 使用全局简化制音开关；音频 MIDI 通道目前合并处理。左右输出为同一弦读出速度信号的双声道复制。

每键的 f0、B、损耗和琴槌参数均由明确单位的估计曲线生成，并携带 `ESTIMATED` 与 `sourceRef`。等律以 A4=440 Hz 为基准；拉伸曲线为 `A4 * 2^(semitones/12 + c * octaves * |octaves| / 1200)`。B 缩放与 f0 调律分离。当前只支持 44.1–192 kHz；低于 44.1 kHz 时 C8 波导几何无法满足最小延迟。

全音域 48 kHz 渲染中，测得 f0 误差范围 −0.0013 至 +0.0032 cents。B=0 与估计 B 在 A0/C4/C8 的最大测得差为 0.001267 cents。释放 voice 采用 `1e-7 m/s` 低阈值、`5e-7 m/s` 高阈值和 0.25 s 滞后；超过低阈值后清除该音的波导状态。没有 limiter。MuseScore Studio 4.5.2 的谱面混音器将 Piano 声部设为 Aether Piano VST3；GUI 导出 C4/E4/G4/C5 四音 WAV 成功。该 32-bit float 文件峰值为 1.627，64 声部直接回调峰值为 15.72；输出是尚未声压标定的弦速度量值，满幅映射与余量留待辐射/输出模型处理。

96 kHz 下低音所需频散相位补偿超出 P02 的 `a >= -0.98` 搜索区间；将系数搜索下界扩至 `-0.999`，仍保留 0.001 的稳定边界，并通过 44.1/48/96/192 kHz 全音域渲染回归及滤波器稳定性、幅频、群延迟端点测试。引擎复音基准测量 `PerformanceEngine::process`；64 帧/32 声部最大 1.866 ms，64 帧/64 声部 3.272 ms，128 帧/32 声部 3.296 ms，128 帧/64 声部 6.365 ms，均超过对应块预算。新增直接调用插件 `AudioProcessor::processBlock` 的基准；分别观察到 3/2250、3/2250、2/1125、2/1125 次壁钟超预算，最大值为 1.642、3.121、3.251、5.983 ms。p99 均低于预算。此基准未使用 DAW 实时音频线程。

## 后果与限制

- 固定 88 个音高槽位限制了资源上界；每键复用状态使同音重复共享一个波导，不模拟独立同音弦。
- CC64 是全局状态，不按 MIDI 通道或踏板机构分组；尚无琴桥、音板、声辐射和完整制音器。
- 速度映射、琴槌和音区曲线均为合成估计；输出仍是弦横向速度 m/s，不是声压或实琴音色结果。
- 64 声部加 CC64/Note Off 序列，以及 JUCE 回调基准均未观察到普通全局 `new/new[]` 分配；未拦截直接 `malloc/free` 或锁 API。回调路径静态检查未见锁或 IO。GUI 调参不适用（无可调 GUI 参数）。基准显示低 p99 wall-time 与低 CPU 占比，但仍有壁钟超预算样本，且不是目标宿主实时线程；在目标宿主硬实时复音验证前，不宣传可保证的最大复音数。

## 回滚

恢复插件到 `PianoEngine`，移除 `PerformanceEngine` 与 `NoteParameters`，并还原 P02 频散搜索区间。P01/P02 参考代码与数据不依赖此决策。
