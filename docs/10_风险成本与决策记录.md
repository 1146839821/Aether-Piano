# 10｜风险登记、研发成本与关键决策

## 技术与产品风险

| ID | 风险 | 概率/影响 | 预警信号 | 缓解策略 |
|---|---|---|---|---|
| K01 | 非线性琴槌离散计算发散 | 高/高 | 极强奏 NaN、接触能量增长 | 离线基准、能量分析、隐式/局部过采样 |
| K02 | 全音域频散与调音相互冲突 | 高/高 | f0 正确但高次泛音严重偏移 | 联合优化 loop 相位、跨音回归 |
| K03 | 多弦/音板耦合非无源 | 高/高 | 踏板时声音自激或衰减异常 | 物理端口功率、稳定散射网络 |
| K04 | 标定参数不可辨识 | 高/高 | 多组参数同样拟合录音 | 分级标定、多测量通道、留出集 |
| K05 | 不能获得足够高质量实物数据 | 中/高 | 仅有商业音源比对 | 早期寻找钢琴/技师/录音协作 |
| K06 | 高复音 CPU 超预算 | 高/高 | 踏板和弦时 callback 超时 | 每阶段测 CPU，分层共鸣，SIMD，模式裁剪 |
| K07 | RT 线程隐藏分配/锁/释放 | 中/高 | 偶发爆音、断音 | RT 探针、线程契约、审查流程 |
| K08 | JUCE/第三方许可冲突 | 中/高 | 无法合法闭源发布 | 早期选择许可，独立保留代码来源账本 |
| K09 | UI/功能开发掩盖核心音质问题 | 高/中 | GUI 先完工，单音仍像电钢琴 | 阶段门：M1 前不做大 GUI |
| K10 | 与 Pianoteq 同一水平被误当保证 | 高/中 | 不做盲听却宣传“等同” | 建立独立参考和指标，不夸大 |

## 成本类别（不要仅估计写代码时间）

- 人：C++/DSP、声学研究、真实钢琴演奏测试、QA/UI。
- 工具：Mac 与 Windows 构建机器、DAW、声卡、校准话筒、配重 MIDI 键盘。
- 数据：原声钢琴、调律师、录音场地、传感器（若用）、录音授权。
- 许可：JUCE 商业许可（如果闭源且不采用 AGPL 路线）、其他依赖合规与代码审计。
- 测试：长时间稳定性、性能样机、宿主环境、发布包/签名。

## 法律与许可证边界

- JUCE 9 采用 AGPLv3 与商业许可路径，闭源发行前必须检查当前许可证并取得合适授权；详情见 [官方 LICENSE](https://github.com/juce-framework/JUCE/blob/master/LICENSE.md)。
- `pluginval` 官方仓库说明是 GPLv3；可以作为**外部测试工具**，但不能未经合规审查将其源代码直接合入闭源产品。
- VST3 SDK 应核对当前版本官方许可证，不沿用旧版本许可传言；参考 [SDK](https://github.com/steinbergmedia/vst3sdk)。
- 论文理论学习不授予作者源码、音源预设、商业样本、钢琴品牌商标的使用权。
- 本内容不是法律意见；正式销售前请做法律/授权审查。

## 核心决策记录（待决）

1. **ADR-001**：波导为主要实现、模态为对照，P02 根据音色/CPU 更新。
2. **ADR-002**：琴槌参考求解器的物理单位/接触算法，P01 决定。
3. **ADR-003**：琴桥与音板反馈的无源散射实现，P04/P05 决定。
4. **ADR-004**：模型参数的公开方式、许可证，P00 前确认研究/闭源路线。
5. **ADR-005**：共鸣优化中允许的近似及最大听感偏差，P06/P10 决定。

## 停止/转向规则

- 如果 C4 的参考模型与波导版本在频散/接触上无法吻合，优先回到 P01/P02，而不是继续开发 GUI。
- 如果同音弦耦合稳定性无法证明，先保持简化的无源网络；明确标注音色限制。
- 如果 P08 的复杂非线性不能在盲听/指标中证明收益，则不进入主干。
- 如果闭源商业许可成本不可承受，按合法许可路径调整产品发行方式，而非忽略许可。
